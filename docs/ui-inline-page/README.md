# Inline PDF page navigation

Screenshots of the actual renderer with a local ten-page fixture PDF, captured in a hidden browser at 1440 by 900. These crops show the preview toolbar at its native size.

- `page-display-*.png`: page 1 of 10, with the current number available to click.
- `page-edit-*.png`: the current-number field active with page 7 typed, before pressing Enter.

The total page count stays visible while editing. Light and dark screenshots use the same document and states.
